👕 Safdar Garments POS

A complete Garments Shop Point of Sale (POS) system built with Python + Streamlit + SQLite.

✨ Features

- 🔐 Admin & Seller Login
- 👑 Admin Dashboard
- 🧑‍💼 Seller Dashboard
- 👕 100 Garments Products
- 📦 Stock Management
- 🛒 Shopping Cart
- 🧾 Invoice / Bill Generation
- 👤 Customer Information
- 💵 Cash Payment
- 📱 JazzCash Payment
- 📱 Easypaisa Payment
- 💳 Credit Card Payment
- 📊 Sales Records
- 💰 Revenue Tracking
- ⬇️ Invoice Download
- ⬇️ Sales CSV Export

🚀 Run Locally

Install requirements:

pip install -r requirements.txt

Start the application:

streamlit run app.py

📁 Project Structure

safdar-garments-pos/
│
├── app.py
├── requirements.txt
├── README.md

☁️ Deploy on Streamlit

1. Upload "app.py" to GitHub.
2. Upload "requirements.txt".
3. Upload this "README.md".
4. Connect your GitHub repository to Streamlit Community Cloud.
5. Select "app.py" as the main file.
6. Deploy.

⚠️ Note

This is a demonstration POS system. For a real production shop, use secure authentication, a persistent cloud database, proper payment-gateway APIs, backups, and secure secrets management.
